Mobile Web Menu

shrink-slide

Designed for modern mobile web experiences, this menu pattern transforms navigation by treating the entire viewport as a dynamic canvas. Instead of simply sliding an overlay over the content, tapping the menu trigger seamlessly scales and shrinks the active web page card downward and shifts it off to the side, revealing a clean, fully accessible navigation drawer in the underlying layer. This spatial transition gives users clear visual context—keeping their current position on the site visible while serving up streamlined links and call-to-action options without jarring screen cuts or clunky drop-downs.


For more information about the shrink&slide, please visit my repo gitHub page.

Web GL animation

threeJS

Engineered for real-time web graphics, this interactive 3D model viewer leverages Three.js and custom WebGL shaders to bring complex 3D assets directly into the browser. Utilizing optimized .glb and .gltf asset pipelines, custom lighting environments, and intuitive OrbitControls, it delivers ultra-smooth 60fps interaction—allowing users to manipulate, inspect, and rotate hardware builds seamlessly without requiring external plugins or heavy load times.
